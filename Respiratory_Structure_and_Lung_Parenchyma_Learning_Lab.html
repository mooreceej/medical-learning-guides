Major map

  1. Diaphragm: attachments, central tendon, T8/T10/T12.
  2. Airway tree: conducting vs respiratory zones.
  3. Flow: ΔP drives air; resistance opposes it; radius dominates.
  4. Dead space: not all inspired air reaches gas-exchange units.
  5. Blood–gas barrier: thin structure enables diffusion.
  6. Parenchyma: compliance lets lungs stretch; elasticity provides stiffness/recoil.

Respiratory Module 1 — Final Review

Diaphragm

  • Origins: costal, sternal, lumbar.
  • Insertion: central tendon.
  • Innervation: phrenic C3–5.
  • Openings: IVC T8 · esophagus T10 · aorta T12.

Airway zones

  • Conducting: upper airway → trachea → bronchi → bronchioles → terminal bronchioles.
  • Respiratory: respiratory bronchioles → alveolar ducts/sacs/alveoli.
  • Alveolus = functional unit.
  • Divergent branching → huge distal cross-sectional/exchange area.

Flow

  • Q = ΔP/R.
  • Air moves high pressure → low pressure.
  • R ∝ 1/r⁴: small radius changes matter a lot.
  • Lecture: smaller airways = laminar; larger + branch points = turbulent.

Dead space

  • Anatomic = conducting air that does not exchange gas.
  • Transcript: ~150 mL in a typical breath.
  • Physiologic = anatomic + alveolar.
  • Alveolar dead space = ventilated, not perfused.
  • Healthy: physiologic ≈ anatomic.

Blood–gas barrier

  • Air → alveolar epithelium → thin basement/interstitial layer → capillary endothelium → blood.
  • Thickening → ↑ diffusion distance → impaired gas transfer.
  • Alveolar septa tether spaces open + contain capillaries.

Compliance vs elasticity

  • Compliance = distensibility.
  • Elasticity = resistance to distention + recoil.
  • Elastin = recoil; collagen = limits overextension.
  • Loss of elastic tissue → ↑ compliance, ↓ recoil.
  • Stiffer tissue → ↓ compliance.

Common traps

  • Do not call terminal bronchioles “respiratory zone.”
  • Do not equate high compliance with strong recoil.
  • Do not forget that normal anatomic dead space is physiologic, not disease.
  • Slide 15’s “capillary epithelium” label should be read as capillary endothelium.
  • IPF imagery is a low-priority preview in this lecture; know the structure–function principle, not disease details yet.

Meaningful clarifications

1) Anatomic dead space wording. Slide 13 uses “trachea + bronchi” as a shorthand. The professor’s own Question 1 treats upper airway structures and bronchioles as anatomic dead space, and the transcript describes the broader conducting zone. Standard references likewise define anatomic dead space as non–gas-exchanging conducting airways, extending through terminal bronchioles. This lab preserves the lecture shorthand but teaches the broader exam-safe definition.
2) “Capillary epithelium” on slide 15. The slide label says epithelium, while the transcript says endothelial cell. Standard anatomy identifies the capillary lining as endothelium. This lab uses endothelium and flags the slide label rather than silently replacing it.
3) IPF images. The transcript explicitly says the fibrosis disease details are not required yet and uses IPF as a demonstration of how altered parenchyma can thicken/destroy exchange surfaces. Current ATS/NCBI descriptions emphasize UIP fibrosis and honeycombing; bullae are a different radiologic concept that can resemble honeycombing in some contexts. The lab therefore tests only the structure–function principle here, not “IPF = bullae/blebs.”
