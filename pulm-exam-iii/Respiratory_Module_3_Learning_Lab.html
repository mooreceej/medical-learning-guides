1. Start here

The reasoning chain

Muscle action → thoracic volume → pressure change → airflow → lung volume/capacity consequence.

Inspiration

Ask which inspiratory muscles are active. If thoracic volume rises, predict pressure and airflow.

Expiration

First decide quiet vs forced. Quiet expiration is passive; forced expiration recruits muscle.

Spirometry

Identify the baseline: normal breath, end-normal-expiration, maximal expiration, or maximal inspiration. Then choose the equation.

Pressures

For TPP, write Palv − Ppl first. A negative Ppl creates the double-negative trap.

8. Exam sheet

Breathing mechanics

  • Quiet inspiration: diaphragm + external intercostals; active.
  • Quiet expiration: inspiratory muscles relax + elastic recoil; passive.
  • Forced inspiration: add accessory muscles.
  • Forced expiration: internal intercostals + abdominals.
  • Tripodding fixes the shoulder girdle so accessory inspiratory muscles can work more effectively.

Volumes

  • TV = normal breath (~500 mL lecture example)
  • IRV = extra inspired above tidal inspiration
  • ERV = extra expired below tidal expiration
  • RV = remains after maximal expiration (~1200 mL lecture example)

Capacities

  • IC = TV + IRV
  • FRC = ERV + RV
  • VC = IRV + TV + ERV
  • TLC = VC + RV

Pressures

  • Atmosphere is the reference: 0 (760 mmHg).
  • TPP = Palv − Ppl.
  • Rest example: 0 − (−5) = +5 cm H₂O.
  • Positive TPP favors expansion / keeps the lung open.

Fast traps

  • VC excludes RV.
  • FRC is after a normal exhalation, not maximal expiration.
  • ERV is extra exhalable air; RV remains.
  • For TPP, subtract the signed intrapleural pressure.
  • Quiet expiration is not muscular.
