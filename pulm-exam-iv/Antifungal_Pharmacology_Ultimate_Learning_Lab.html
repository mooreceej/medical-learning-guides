1. Start here

Use the target map first. Then learn each class as a predictable package instead of memorizing disconnected facts.

The reasoning loop

Fungal structure/pathway→ Drug target→ Cell effect→ Spectrum→ PK / penetration→ Signature toxicity
Stem decoder: if a question gives you an organism, ask “which class reaches it?” If it gives a toxicity, reverse the chain: toxicity → drug → target → likely organism.

Normal fungal targets you need

  • Cell wall: chitin + glucans provide structural integrity.
  • Cell membrane: fungi use ergosterol, whereas human membranes use cholesterol.
  • Nucleic acids: fungi can convert flucytosine to 5-FU using cytosine deaminase.
  • Mitosis: tubulin and the mitotic spindle remain vulnerable targets.

Question: What fungal structure is being destabilized, and what enzyme target does this imply?

Answer: Cell wall β-glucan network → β-1,3-D-glucan synthase → echinocandins. Trap poor CNS/urine/eye penetration.

Figure challenge 2

Question: Which sterol-synthesis step is blocked, and what membrane consequence follows?

Answer: Azoles inhibit C-14α demethylase, preventing lanosterol → ergosterol conversion; abnormal sterols produce membrane stress.
Source: slide 16.
Figure challenge 3

Question: Which fungal enzyme creates the active antimetabolite, and what toxicity should that mechanism make you predict?

Answer: Cytosine deaminase converts flucytosine to 5-FU; predict chemotherapy-like toxicity, especially marrow suppression and GI effects.
Source: slide 23.

Question-stem decoder

If you see… edema + new reduced EFThink itraconazole toxicity before you chase the fungus.
If you see… visual hallucinationsThink voriconazole; then check whether Aspergillus is the infection.
If you see… pancytopeniaThink flucytosine → 5-FU → marrow suppression.
If you see… rigors + low K/MgThink amphotericin B infusion + nephrotoxicity.
If you see… “all of the following except” with fluconazoleUse the 3 C’s; Aspergillus is the likely outsider.
If you see… CNS/urinary/ocular CandidaDo not reflexively choose an echinocandin; penetration is poor.
If you see… nail fungus + taste changesThink terbinafine, then remember liver monitoring.
If you see… “fungal enzyme not found in humans”Could be β-glucan synthase (echinocandins) or cytosine deaminase (flucytosine); use the rest of the mechanism.

Professor-emphasized nuances & traps

  • Nuance Echinocandin slides list Aspergillus/Pneumocystis activity, but the transcript’s practical exam framing is “the echinocandins are for Candida.”
  • Trap Liposomal amphotericin B is preferred systemically, but the older deoxycholate formulation can achieve bladder exposure better.
  • Nuance Meperidine can stop amphotericin-associated rigors; this came from the transcript rather than the formal objective.
  • Trap IV voriconazole renal toxicity is linked to its cyclodextrin vehicle, not the active drug itself.
  • Nuance Griseofulvin is clinically de-emphasized by the lecturer, but it remains explicitly listed in the objective and therefore stays in this sheet.
